# MedLearn

Mobile-first medical learning platform built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Dashboard
- Medical subjects and progress
- Electronic books with search/sort
- Book detail and reader
- Reader chapter navigation, font controls and reading theme
- Functional test demo with timer, navigation and scoring
- Results analysis
- Favorites
- Profile and achievements
- Settings and theme
- LocalStorage persistence
- Responsive mobile/desktop layout
- GitHub Pages compatible

## Run locally
Open `index.html` in a modern browser. No npm or backend is required.

## GitHub Pages
This repository is a static site. The entry point is `index.html`.
